1. 端到端主流程：网表 → L3 → 逐域 L2/L1 → L0 → 导出

  PARSEJSON --> NORM

  CHECK3B -->|是| SAVE3

  PLACEHOLDER --> SAVE3

  SUBSET --> L2[运行 L2：DeepSeek 功能识别 → 本地算法初划分 → 条件式 DeepSeek 补划分]
  L2 --> L2OK{L2 最终归属完整且唯一？}

在每个 L2 内本地计算器件配对并成簇]
  L1 --> SAVE1[保存该 L3 域的 L1 结果与配对分数]
  SAVE1 --> MORE{还有未处理的 L3 域？}
  MORE -->|是| LOOP
  MORE -->|否| MERGE[合并所有域结果
建立 L3 → L2 → L1 层级]
  MERGE --> L0[每个 L1 成员生成一个单器件 L0 簇
识别连接器并标记]
  L0 --> GLOBAL{全局器件校验通过？
每个输入器件恰好归属一个 L0}
  GLOBAL -->|否| FAIL
  GLOBAL -->|是| CSVCHK{L3/L2/L1/L0 分层 CSV 覆盖及唯一性校验通过？}
  CSVCHK -->|否| FAIL
  CSVCHK -->|是| OUT[输出 hierarchy.json、总归属 CSV、四层 assignments CSV、run.json]
  OUT --> DONE([完成])
  FAIL[捕获异常；尽量写 flow_error.json] --> EXIT([打印运行失败原因并退出])

2. L2 展开：功能识别、算法初划分、DeepSeek 小器件补划分

flowchart TB
  A([输入：一个 L3 域的器件与网络子网表]) --> B[加载并规范化网表 / 拓扑；保存输入与算法拓扑]
  B --> C[解析 DeepSeek 配置
API Key、Base URL、模型、temperature、timeout]
  C --> DRY{dry-run？}
  DRY -->|是| MOCK[不调用模型；生成待识别占位功能标注]
  DRY -->|否| FREQ[构造器件功能识别请求
每个器件输出类别、描述、证据、置信度]
  FREQ --> DSF[DeepSeek：识别当前域所有器件功能]
  DSF --> FVALID{JSON 与器件标注覆盖有效？}
  FVALID -->|否| FERR[带校验错误重问 / 修复一次]
  FERR --> FVALID2{修复后有效？}
  FVALID2 -->|否| ERR([异常终止 L2 / 总流程])
  FVALID2 -->|是| ANNO[保存 device_function_annotations JSON / CSV
并兼容写 device_annotations 别名]
  FVALID -->|是| ANNO
  MOCK --> ANNO
  ANNO --> ALG[本地确定性算法初划分
验证拓扑；运行 hierarchical 模式
不调用 LLM，不学习软约束]
  ALG --> EXTRACT[抽取算法 L2 域、锚定域、未解决器件
算法遗漏器件补入无锚点回退域]
  EXTRACT --> ELIGIBLE[候选筛选：未解决的小器件可补划分
未解决的大器件不送补划分]
  ELIGIBLE --> TARGET{存在锚定大器件域？}
  TARGET -->|否| NOTARGET[没有合理补划分目标
eligible 为空，小器件记为无目标并保留审计信息]
  TARGET -->|是| HAS{是否存在未解决小器件 eligible？}
  HAS -->|否| NONE[没有候选小器件；不调用补划分模型]
  HAS -->|是| DRY2{dry-run？}
  DRY2 -->|是| SKIP[跳过 DeepSeek 补划分
使用算法初划分结果及回退域]
  DRY2 -->|否| REQ[构造小器件补划分请求
候选器件、全量功能标注、候选标注、关联网络、算法 L2 域]
  REQ --> RULES[约束：保留现有锚定域且不移动其成员
补划分器件只能进入独立辅助簇，不能分配给大器件域]
  RULES --> DSS[DeepSeek：只补划分 eligible 小器件]
  DSS --> CVALID{clusters 完整且合法？
候选全覆盖、唯一；引用合法；网络证据有效}
  CVALID -->|否| CREPAIR[附错误发送一次修复请求
要求只输出合法 clusters，不得漏项或重复]
  CREPAIR --> CVALID2{修复后有效？}
  CVALID2 -->|否| ERR
  CVALID2 -->|是| AUX[形成独立辅助 L2 域及 completion_assignments]
  CVALID -->|是| AUX
  AUX --> MERGE
  NOTARGET --> MERGE[组合算法域与辅助域
完成补划分的器件从旧无锚点回退域移除
锚定大器件域原样保留]
  NONE --> MERGE
  SKIP --> MERGE
  MERGE --> FINAL{最终 L2 校验：无遗漏、无额外器件、无重复归属？}
  FINAL -->|否| ERR
  FINAL -->|是| WRITE[写 l2_final_result.json
l2_final_assignments.csv、flow_manifest.json]
  WRITE --> NEXT([返回 L2 域与功能标注，供 L1 使用])

4. 各阶段产物与执行边界

输入标准 JSON 网表或 EasyEDA .enet；不需要原理图图片。
L3 模型普通运行由 DeepSeek 按阈值划分电压域；dry-run 仅写临时 low_voltage 占位。
L2 模型DeepSeek 识别当前 L3 域全部器件功能；有条件时再调用 DeepSeek 补小器件。
L2 算法本地确定性初划分建立 L2 域；LLM 补划分不得改动锚定大器件域。
L1 算法本地基于 L2 内拓扑和功能分数贪心配对；没有 L1 模型调用。
L0 / 校验逐器件生成 L0；层级及四份层级 CSV 均检查覆盖和唯一性。
路径 / 文件作用
normalized_netlist.json根流程规范化后的完整输入网表。
l3/L3 请求、输入、模型响应、电压域 JSON/CSV 与 L3 run 信息。
domains/<L3域>/input_netlist.json该 L3 域的器件与关联网络子网表。
domains/<L3域>/l2/L2 功能请求/标注、算法拓扑/初划分、补划分请求、最终结果及归属表。
domains/<L3域>/l1/L1 配对评分、L1 结果与归属 CSV。
hierarchy.jsonL3→L2→L1→L0 嵌套结果、总归属和分层耗时。
hierarchical_assignments.csv每个器件对应的 L3/L2/L1/L0 ID 和连接器标记。
L3_assignments.csv 至 L0_assignments.csv按层级导出的逐器件归属表，并进行层级覆盖/唯一性校验。
run.json / flow_error.json成功时记录数量、阶段耗时、产物索引；失败时尽量记录异常类型和原因。
流程按划分器 v1.1 当前代码实现绘制。若模型响应或修复后仍不满足 schema / 覆盖要求，或接口及下游阶段抛出异常，主流程会记录错误并停止，不会将失败结果伪装成成功划分。
